# Команды плагина

## Основные команды

| Команда | Описание |
|---------|----------|
| `INS` | Раскладка утеплителя |
| `INS_CHECK` | Проверка контуров |
| `INS_DEL` | Удалить раскладку с чертежа |
| `INS_STOCK` | Статистика склада остатков |
| `INS_STOCK_IMPORT` | Импорт начального склада из Excel |
| `INS_CLR` | Очистить склад остатков |

---

## INS — раскладка утеплителя

Основная команда. Выполняет полный цикл:

1. Поиск контуров фасадов и окон
2. Валидация геометрии
3. Деление на ряды (600 мм, Trim-to-Target)
4. OR-Tools CP-SAT оптимизация (Rolling Horizon)
5. Визуализация и отчёт

**Диалог:** при запуске спрашивает «1 ряд с выпуском?»
- **Да** → выпуск начинается с 1-го ряда
- **Нет** → выпуск со 2-го ряда

## INS_CHECK — проверка контуров

Проверяет:
- Замкнутость полилиний
- Самопересечения
- Расположение окон относительно фасадов

## INS_DEL — удалить раскладку

Удаляет все объекты на слоях `INS_NEW`, `INS_REUSE`, `INS_HATCH` и аннотации.

## INS_STOCK — склад остатков

Показывает статистику базы данных:
- Количество остатков
- Суммарная площадь
- Размеры каждого остатка

## INS_STOCK_IMPORT — импорт начального склада

Загружает начальный склад из листа **«Нач. склад»** файла `C:\DB_INS\remnants.xlsx`.
Полностью заменяет текущие неиспользованные остатки на записи из Excel.
История (`IsUsed = true`) сохраняется.

**Типичный сценарий:**
1. Выполнить `INS` — в `remnants.xlsx` создаётся лист «Нач. склад» с шаблоном и текущим складом
2. Открыть `C:\DB_INS\remnants.xlsx`, отредактировать лист «Нач. склад»
3. В AutoCAD: `INS_STOCK_IMPORT` — склад заменяется данными из таблицы

**Формат листа «Нач. склад»:**

| Ширина (мм) | Высота (мм) | Количество (шт.) |
|-------------|-------------|------------------|
| 1200 | 600 | 2 |
| 800 | 400 | 1 |
| … | … | … |

**Правила:**
- Минимальный размер: **150 × 150 мм** (строки с меньшим размером пропускаются)
- Столбец «Количество» опциональный — по умолчанию 1 шт.
- Перед заменой автоматически создаётся бэкап: `C:\DB_INS\backups\remnants_backup_*.json`
- Поле `Source` каждого импортированного остатка: `IMPORT_YYYYMMDDHHMMSS_NNN`

**Если файл или лист не найден:**
```
❌ Файл не найден: C:\DB_INS\remnants.xlsx
   Создайте файл командой INS или скопируйте шаблон.

❌ Лист «Нач. склад» не найден в файле.
   Выполните INS чтобы создать шаблонный лист.
```

## INS_CLR — очистить склад

Полностью очищает базу остатков. Перед очисткой создаётся бэкап:
```
C:\DB_INS\backups\remnants_backup_YYYYMMDD_HHMMSS.json
```

## Результаты работы

### Визуализация на чертеже

| Слой | Цвет | Содержимое |
|------|------|-----------|
| `INS_NEW` | Зелёный | Новые плиты |
| `INS_REUSE` | Жёлтый | Плиты из остатков |
| `INS_HATCH` | Красный | Штриховка перекрытий с окнами |

**Аннотации** — MText, 60 мм, двустрочный формат:
```
1200x210
0003
```
Первая строка — размер (ширина × высота). Вторая — номер блока.

**Нумерация блоков (v3.5.0, формат X.Y.NNN.ZZ):**
- `1.3.014` — фасад 1, ряд 3, плита 14
- `1.3.014.01` — первый остаток от плиты 1.3.014
- `1.3.014.02` — второй остаток (от остатка .01)
- На чертеже: `DisplayNumber` = `BlockNumber`

**Легенда** — сводка раскладки в правом нижнем углу чертежа.

### Текстовый отчёт

Файл `Insulation_Report_YYYYMMDD_HHMMSS.txt` в папке с чертежом:

```
=====================================
INSULATION MASTER PRO - ОТЧЕТ
=====================================
Дата: 19.03.2026 14:30:25

ОСНОВНАЯ СТАТИСТИКА:
Новые плиты: 45 шт. (32.40 м²)
Использовано остатков: 12 шт. (4.32 м²)
Общая площадь утепления: 36.72 м²

МАТЕРИАЛЬНЫЙ БАЛАНС:
Площадь фасада (брутто): 52.800 м²
Площадь проёмов: 8.640 м²
Чистая площадь утепления (100%): 44.160 м²
Новый материал: 45 плит × 0.72 м² = 32.400 м²
  → уложено: 30.240 м²  |  → на склад: 1.440 м²  |  → отходы: 0.720 м²
Перерасход: +10.5%  |  КПД раскроя: 82.3%

ДВИЖЕНИЕ ОСТАТКОВ:
  N0001: Новая → 1200x600 → использована 1200x210, остаток 1200x390
  R0001: Остаток 1200x390 → использован 1200x210, остаток 1200x180
  ...
=====================================
```

### Excel-отчёт

Файл `C:\DB_INS\remnants.xlsx` — **4 листа** при полном экспорте после `INS` (`RemnantExcelExporter.UpdateWithMovement`):

| Лист | Содержимое |
|------|-----------|
| **Статистика** | Секция А (сводка склада), Б (нетто/закупка/остатки/отходы/перерасход), В (материальный баланс), Г (проверка перерасхода) |
| **Движение остатков** | Начальный склад → использованные → созданные |
| **Сводная** | Плиты на фасаде: номер (X.Y.NNN.ZZ), ряд, размер, площадь, тип, источник, остаток + размер |
| **Нач. склад** | Шаблон для ввода начального склада — заполните и запустите `INS_STOCK_IMPORT` |

Упрощённый режим `SaveToExcel` (только склад) — один лист «Статистика».

### Диагностический файл (v2.9)

При каждом запуске `INS` создаются 2 файла (**перезаписываются**):

| Файл | Формат | Назначение |
|------|--------|------------|
| `C:\DB_INS\diagnostics.txt` | TXT | Человекочитаемый отчёт, 10 секций |
| `C:\DB_INS\diagnostics.json` | JSON | Машиночитаемый — для AI-анализа |

**10 секций TXT:**

1. Входные данные (фасад, окна, склад)
2. Параметры оптимизации (все constraints)
3. Деление на ряды (высота, тип, сегменты)
4. Solver (статус, время, Rolling Horizon)
5. Раскладка по рядам (каждый блок с координатами)
6. Маркировка (N0001, N0001.1, R0001 — полная карта)
7. Материальный баланс (площади, проценты, КПД)
8. Склад после раскладки (использовано, создано)
9. Валидация ограничений (C1, C4, C12a, CH — pass/fail)
10. Предупреждения и ошибки
