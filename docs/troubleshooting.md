# Устранение проблем

## Частые ошибки

### «Не найдено замкнутых полилиний на слое»

**Причина:** Отсутствуют контуры или неверное название слоя.

**Решение:**
1. Проверьте названия слоёв: `Внешний контур фасада` и `Контуры окон` (точно)
2. Убедитесь, что полилинии замкнуты
3. `INS_CHECK` для диагностики

### «Контур имеет самопересечения»

**Причина:** Полилиния пересекает саму себя.

**Решение:**
1. `_OVERKILL` для очистки
2. Перерисуйте контур
3. `INS_CHECK` для поиска проблем

### Медленная работа на больших фасадах

**Причина:** Много вершин, сложная геометрия.

**Решение:**
1. Упростите контуры (`_SIMPLIFY`)
2. Разбейте большой фасад на два
3. Уменьшите количество вершин (< 100)

### Некорректная раскладка у сложных окон

**Причина:** Геометрически сложные проёмы.

**Решение:**
1. Упростите контуры окон
2. Разделите сложный проём на несколько
3. Минимальное расстояние между окнами: 150 мм

## Советы по оптимизации

### Эффективное использование остатков

- `INS_STOCK` — регулярно проверяйте склад
- Планируйте раскладку с учётом имеющихся остатков
- Крупные остатки используются в первую очередь

### Качество геометрии

- `F8` (ортомодаль) при рисовании контуров
- Проверяйте замкнутость перед запуском
- Избегайте фрагментов < 150 мм

## Excel не генерируется в AutoCAD

**Причина:** ClosedXML может не загружаться внутри AutoCAD из-за `FileLoadException (0x80131621)`.

**Решение:** Плагин автоматически использует fallback через `ExcelGenerator.exe` — отдельный процесс:
1. Данные сериализуются в `C:\DB_INS\excel_input.json`
2. Запускается `ExcelGenerator.exe` из папки плагина
3. Excel-файл создаётся в отдельном процессе

Если `ExcelGenerator.exe` не найден — убедитесь, что он скопирован в папку плагина рядом с `InsulationMasterPro.dll`.

## Логирование и диагностика

### Номер плиты «1.14.…» вверху списка / «остаток из другого ряда»

**Смысл нумерации:** `X.Y.NNN` — фасад **X**, ряд **Y** (1-based, снизу вверх), плита **NNN** в ряду. Остаток: `X.Y.NNN.ZZ`.

- Остаток от плиты ряда 14 может **легитимно** стоять в той же строке Excel, что и плита ряда 16 — лист «Сводная» часто отсортирован не по ряду, а по порядку обхода/номеру. Смотрите колонку **Ряд** или секцию **5. РАСКЛАДКА ПО РЯДАМ** в `diagnostics.txt`.
- После **v3.4.1** пост-оптимизация не подмешивает в нижний ряд остатки, созданные **выше** по фасаду; дубли L-boot в отчёте «созданные» устранены.

### Деплой при заблокированных файлах

**Причина:** AutoCAD блокирует DLL-файлы плагина. `deploy.ps1` не может их перезаписать.

**Решение:** `deploy.ps1` (v3.5.0) автоматически переименовывает заблокированные файлы в `.bak` и копирует новые. Или используйте `.\dev.ps1`, который закроет AutoCAD перед деплоем.

### Полная диагностика (v3.5.0)

```
C:\DB_INS\diagnostics.txt    — 10 секций, человекочитаемый TXT
C:\DB_INS\diagnostics.json   — зеркало для AI-анализа
```

Создаются **при каждом запуске** `INS`, перезаписываются.

```
C:\DB_INS\backups\remnants_backup_YYYYMMDD_HHMMSS.json
```
