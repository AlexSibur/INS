ТЗ: Работа с несколькими фасадами (Multi-Facade Support)
Система InsulationMasterPro поддерживает одновременную раскладку и оптимизацию нескольких фасадов на одном чертеже. Это позволяет синхронизировать горизонтальные швы и автоматически формировать угловые замки (перевязку углов) между фасадами.

1. Подготовка чертежа и слои
Элемент	Слой	Тип объекта
Контур фасада	Внешний контур фасада	Замкнутая полилиния (LWPOLYLINE)
Окна	Контуры окон	Замкнутые полилинии
Фасады и окна могут быть расположены в любой части модели.
Система автоматически фильтрует окна: окно считается принадлежащим фасаду, если геометрический центр окна попадает внутрь границ фасада (допуск 10 мм).
2. Логика группировки и очередность (Sorting)
Для корректной нумерации и синхронизации система выполняет двухэтапную сортировку:

По рядам (сверху вниз): Фасады группируются в горизонтальные ряды по близости их центральных координат Y (допуск 10 мм). Верхние ряды фасадов обрабатываются первыми.
По горизонтали (слева направо): Внутри каждого ряда фасады сортируются по координате X (от меньшего к большему).
Результат: Фасад №1 — самый верхний левый, Фасад №2 — правее него и т.д.

3. Синхронизация высоты рядов (Row Sync)
Это ключевая функция для обеспечения единого горизонтального рисунка швов по всему зданию:

Мастер-фасад: Высоты рядов (например, 600, 600, 450, 150 мм) рассчитываются интеллектуальным оптимизатором только для Фасада №1.
Тиражирование: Для всех остальных фасадов (№2, №3...) система принудительно применяет те же самые высоты рядов, что были получены для первого фасада.
Адаптация: Если высота фасада №2 отличается от №1:
Фасад короче: верхние ряды отсекаются.
Фасад длиннее: сверху добавляются дополнительные ряды стандартной высоты (600 мм).
4. Зеркалирование выпусков (Corner Interlock)
Для автоматического формирования «замка» на углах (перевязка плит) система использует логику зеркалирования:

Нечетные фасады (1, 3, 5...): Первый ряд получает выпуск (overhang) согласно выбору пользователя в диалоге (Да/Нет).
Четные фасады (2, 4, 6...): Логика первого ряда инвертируется.
Эффект: Если Фасад 1 начинается с выпуска, а Фасад 2 (примыкающий к нему на углу) начинается без выпуска — на угле образуется корректный перехлест плит.
5. Визуальная маркировка на чертеже
Для удобства навигации система добавляет аннотации на слое INS_FACADE_LABELS:

Номер фасада:
Текст: «1 фасад», «2 фасад»...
Высота: 300 мм.
Позиция: По центру фасада (X), на 400 мм выше верхней границы.
Номера рядов:
Текст: «1», «2», «3»...
Высота: 150 мм.
Позиция: Слева от фасада на 400 мм от края, по центру каждого ряда по высоте.
Нумерация: Сниза вверх (ряд 1 — самый нижний).
6. Отчетность и Excel (remnants.xlsx)
Лист «Статистика»: Сводные данные по всем фасадам.
Листы «Ф1», «Ф2»...: Детальные спецификации для каждого фасада.
Лист «Сводная»: Общий перечень материала по всем фасадам.
Лист «Нач. склад»: Единый шаблон для загрузки остатков (команда INS_STOCK_IMPORT).
